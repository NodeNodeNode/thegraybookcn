## Char / 字符 {#char}

单个字符用 Char 这个数据类型来表示。`'A'` 就是 Char 类型的数据。

## String / 字符串 {#string}

一段文本由一串字符组成，这种类型叫 String。`"Hello World!"` 就是 String 类型。
