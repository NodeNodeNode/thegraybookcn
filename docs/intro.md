这里是 [the gray book](https://thegraybook.vvvv.org/) 的中文站 —— vvvv gamma 官方文档的社区中文翻译。非官方站点，由 vvvv 中文社区维护。

上游官方文档在持续更新，我们的目标是**跟得上它**：上游导航里的每一页，这里都有对应的中文。

## 这些译文是 AI 翻译的

我们用 AI 做初翻，再配合人工审校和一套机器检查（术语一致性、锚点、链接、渲染）来兜底。

这么做的理由很直接：灰皮书有十几万词，靠零散的业余时间逐页人译，现实里的结果是**翻到一半就停了，然后上游又跑远了** —— 这个站此前就停了四年。AI 让「全部覆盖」和「跟上更新」第一次变得可能。

代价也要说清楚：**有些地方会生硬，有些地方会走味，个别地方可能理解错了。** 术语我们锁得很死（有一份机器可读的术语表在把关），但语感和上下文判断，AI 仍然不如一个真正用过这个功能的人。

所以：

:::tip[你读着不顺，多半不是你的问题]
如果某句话读起来别扭、或者跟你的实际使用经验对不上，**很可能就是翻译的问题**。别怀疑自己，来帮我们改掉它。
:::

## 发现问题，怎么帮我们

按顺手程度排，随便挑一种：

**一、直接对照原文。** 每一页正文最上面都有一条「源文档地址」，点开就是这一页的英文原文。对照一眼就知道是不是译歪了。

**二、直接改。** 每一页最下面有「编辑此页」，点开就是 GitHub 的在线编辑器，改完提交即可。**改一个错别字也算**，不必凑成一整章。

**三、说一声就行。** 不想碰 GitHub 也完全没关系：

* 到 [Discord](https://discord.com/invite/yBWCJQQ4Pq) 说一句哪页哪句不对
* 或者发邮件到 [info@nodenodenode.net](mailto:info@nodenodenode.net)

哪怕只是「这句我读了三遍没读懂」，对我们也是有用的信息 —— 读不懂本身就是要修的缺陷。

## 一点说明

翻译的过程往往就是信息丢失的过程，很难非常精确地传递原本的意思。但本着深入浅出与抛砖引玉的信念，多少是个好的开始。

拿不准的时候，**以[英文原文](https://thegraybook.vvvv.org/)为准**。
