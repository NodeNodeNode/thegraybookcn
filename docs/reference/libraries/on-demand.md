[源文档地址](https://thegraybook.vvvv.org/reference/libraries/on-demand.html)

如果你发现缺少对某个特定设备或库的支持，它几乎一定可以按需加上。

vvvv 的节点库全部[开源](https://github.com/vvvv)，对程序员来说，用自定义的一组节点去[扩展](/extending/)它们相当容易。

我们也为你的开发需求提供优先支持，请[**联系我们**](mailto:devvvvs@vvvv.org)，看看能不能一起把事情办成。

下面是一些你可能正在找的东西：

* 对特定相机设备的支持（比如 [Ensenso](https://www.optonic.com/en/brands/ensenso/)、[Ximea](https://www.ximea.com/)、通过 [Spinnaker SDK](https://www.teledynevisionsolutions.com/products/spinnaker-sdk/?model=Spinnaker%20SDK&vertical=machine%20vision&segment=iis) 的 [FLIR（Point Grey……）](https://ptgreycamera.com/product-category/camera/flir/)……）
* 对特定采集卡的支持
* 激光雷达
  * [Ouster](https://ouster.com)
  * [Sick](https://www.sick.com/)
* 对特定协议的支持
* [Laser Animation Sollinger](https://laseranimation.com/) 的激光设备
* 对 [ShowNET 硬件](https://www.laserworld.com/de/software/shownet-hardware.html)的支持
* 对特定 [OpenXR 扩展](https://registry.khronos.org/OpenXR/specs/1.0/html/xrspec.html)的支持
* 通过 [EasyAR](https://www.easyar.com/) 实现的平面图像追踪等等
* VESA [MPCDI](https://vesa.org/featured-articles/vesa-completes-specifications-for-new-multiple-projector-common-data-interchange-standard-mpcdi/)
* [Notch LC](https://notchlc.notch.one/) 视频编解码器
* [ProRes](https://support.apple.com/en-us/102207) 视频编解码器
* [Python](https://github.com/pythonnet/pythonnet) 脚本
* [Crestron](https://www.crestron.com/)
* 动作捕捉
  * [BlackTrax](https://cast-soft.com/blacktrax/)
  * [Vicon](https://www.vicon.com/)
  * [Captury](https://captury.com/)
* NVIDIA [Rivermax](https://developer.nvidia.com/networking/rivermax)
* 与其他系统的集成
  * [Disguise](https://www.disguise.one/)（[RenderStream](https://www.disguise.one/en/products/renderstream)）
  * [7th Sense](https://7thsense.one/)
  * [Green Hippo](https://www.green-hippo.com/)
  * [TouchDesigner](https://derivative.ca/)（[TouchEngine](https://docs.derivative.ca/TouchEngine)）
  * [Unreal Engine](https://www.unrealengine.com)
  * [Ventuz](https://www.ventuz.com/)
  * [Brainsalt](https://www.brainsalt.com/)
  * [Pixera](https://pixera.one/en/)

所以，如果你对上面任何一项感兴趣，请[联系我们](mailto:devvvvs@vvvv.org)。
