vvvv 自己不带编辑 C# 代码的编辑器，你可以自己选一个。这里是几个建议：

## Visual Studio {#visual-studio}

[Visual Studio](https://visualstudio.microsoft.com/) 2022 及以上

安装时记得勾选「.NET 桌面开发」工作负载。

![](https://thegraybook.vvvv.org/images/reference/extending/vs-workload.png)

## Visual Studio Code {#visual-studio-code}

[Visual Studio Code](https://code.visualstudio.com/)

装好之后记得再装 “C# Dev Kit” 扩展。

![](https://thegraybook.vvvv.org/images/reference/extending/vsc-extension.png)

## JetBrains Rider {#jetbrains-rider}

[JetBrains Rider](https://www.jetbrains.com/rider/)

## Text Editors / 文本编辑器 {#text-editors}

如果上面这些编辑器你一个都没有，那么其实随便哪个文本编辑器都能用来改 C# 代码。显然你会少掉一些便利，但对简单的情形来说，这也许就够了。
