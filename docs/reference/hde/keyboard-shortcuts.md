## Alternative Pan & Zoom / 另一套平移与缩放 {#alternative-pan--zoom}

如果你更希望用滚轮做垂直平移而不是缩放，把设置里的 “Mouse wheel zooms” 改成 false，就会变成下面这套行为：

| 操作 | 按键 |
|---|---|
| 垂直平移草图 | 鼠标滚轮 |
| 水平平移草图 | <span class="keyseq"><kbd>Shift</kbd></span> + 滚轮 |
| 缩放草图 | <span class="keyseq"><kbd>Ctrl</kbd></span> + 滚轮 |
