## .v4p versus .vl / .v4p 与 .vl 的区别 {#v4p-versus-vl}

在 vvvv beta 里，每个草图都有自己的 .v4p 文件。VL 不是这样：多个草图可以装在同一个 .vl 文件里 —— 我们把它叫做 VL 文档。所以小的 VL 项目通常只有一个 VL 文档，哪怕它由好几个草图组成。

VL 里还有不同类型的草图，可以在[草图](../../language/patches.md)那一节了解。

其中[Process 草图](../../language/patches.md#process)最接近你在 vvvv beta 里熟悉的那种。想知道怎么把一组节点打包进一个新草图，看 [HowTo Make a Node](https://youtu.be/wEziL9RTkMM)。
