边框用来在视觉上组织你的草图。你可以在草图的某一部分背后放一个边框，给它加上标题和颜色。

边框相关的全部快捷键，见 [边框快捷键（英文）](https://thegraybook.vvvv.org/reference/hde/keyboard-shortcuts.html#Frames)。

![](https://thegraybook.vvvv.org/images/language/frame.png)

选中之后，可以从几个预设颜色里挑一个给边框上色：

![](https://thegraybook.vvvv.org/images/language/frame-selected.png)

拖动（选中状态下的）灰色横条，可以只移动边框而不带走里面的内容。想连内容一起移动，就拖它的标题。

## Screenshots / 截图 {#screenshots}

边框不只是结构元素，它还让截图这件事变得容易且可重复：

* 按打印机按钮截图，然后右键点它，就能在资源管理器里看到截出来的文件
* 或者按 `Ctrl` `+` `2`，截取当前选中的边框
* 按 `Ctrl` `+` `5`，一次性截取文档里所有的边框

想快速截一块区域、连边框都懒得建，那就在框选的同时按 `S`。截图会被复制到剪贴板（可以直接粘进聊天或论坛回复），同时还会在当前 .vl 文档旁边生成一个 .png。

## Recordings / 录制 {#recordings}

除了截静态图，你还可以把边框范围内的画面录成动图：

* 按录制按钮开始录，再按一次同一个按钮或者按 `Esc` 停止，然后右键点它，就能在资源管理器里看到录下来的文件
* 或者用 `Ctrl` `+` `4` 来切换开始／停止录制当前选中的边框
