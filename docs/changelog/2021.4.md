## vvvv gamma 2021.4.12

2022 年 12 月 6 日发布
[安装包](https://teamcity.vvvv.org/guestAuth/app/rest/builds/id:36679/artifacts/content/vvvv_gamma_2021.4.12_setup.exe) |
[离线安装包](https://teamcity.vvvv.org/guestAuth/app/rest/builds/id:36679/artifacts/content/vvvv_gamma_2021.4.12_setup_offline.exe)

### 修复

* 修复了 `LottiePlayer (Skia)`，现在动画播放流畅了。另外加了 `LottiePlayer (Framebased Skia)` —— [论坛](https://forum.vvvv.org/t/lottie-playback-not-working-correctly/21006)
* 修复了 `Synchronizer` 区块导致 emit 异常
* 这个版本解决了几个与运行时异常有关的问题：
  * 反序列化失败时，针脚和 IOBox 会变粉 —— 此前这类错误只在日志里看得到
  * 若编译期就知道反序列化不会成功，编译器会在针脚和 IOBox 上加一条警告
  * 此前定位运行时异常发生的草图位置有很大延迟 —— 现在修好了，系统应该会立刻导航过去
  * 若一帧里发生多个异常，系统现在会把用户指向第一个
  * 有些 Observable 图里的运行时异常此前完全不显示
* 2021.4.11 引入的下列回归已处理：
  * 着色器上的 Open 命令不工作
  * 着色器内部的错误在节点上看不到
  * 双击文档标签重命名不该再抛异常
  * 通过 `CreateInstance` 动态创建实例时，泛化类型上有时会崩溃
* 修复了「设置 > 主题」。默认主题和自定义主题分得更清楚了 —— [论坛](https://forum.vvvv.org/t/when-you-add-custom-themes-the-default-themes-are-also-replaced/21019)
* 扩展与 HDE 控件：默认流畅更新，并在帮助面板的 learn 区做了优化
* 针脚会与节点、数据板和 BCP 对齐
* 安全网：编译器后端的编译错误现在会让对象变成过期的。作为用户，你显然不想让一个没反映你最新改动的程序跑着
* 重新启用了提示框上「按 [TAB] 分离」的提示
* 草图里网格可视化的一处小改进

## vvvv gamma 2021.4.11

2022 年 11 月 12 日发布
[安装包](https://teamcity.vvvv.org/guestAuth/app/rest/builds/id:36569/artifacts/content/vvvv_gamma_2021.4.11_setup.exe) |
[离线安装包](https://teamcity.vvvv.org/guestAuth/app/rest/builds/id:36569/artifacts/content/vvvv_gamma_2021.4.11_setup_offline.exe)

### 新增

* 你现在可以用 Skia [播放 Lottie 文件（英文）](https://visualprogramming.net/blog/2022/introducing-lottie/)了
* 你现在可以把自己作品的[截图分享（英文）](https://visualprogramming.net/blog/2022/introducing-show-tell)到我们的[集体画廊](https://pixelfed.social/madewithvvvv)。按 `Ctrl` + `3`。
* 你现在可以给 Skia 和 Stride 渲染器截图。按 `Ctrl` + `2`。
* 新的命令行选项 `--nuget-path`，用来指定主包文件夹 —— [论坛](https://forum.vvvv.org/t/vvvv-projects-self-contained-vs-global-package-repositories/20754/10)
* 新的命令行选项 `--stoppedonstartup`，启动 vvvv 但不启动任何用户草图
* 现在可以为自定义区块指定支持哪些边界控制点，以及施加什么类型约束
* 加了 Channel [Reactive] 和大量绑定运算符 —— 比如用来照料业务逻辑与界面之间的双向通信。还加了一个好用的区块：ForEach (Channel)。
* 加了 KeepAlive [Resources] 节点。你可以把东西交给它然后忘掉，别人稍后再来取。我们用它在运行时意外关闭的情况下保住帮助面板的可见性信息。
* 多亏了新的、对热替换友好的目标代码，垃圾回收器的压力大幅下降，修复了在草图编辑器里运行时的大量卡顿／掉帧。导出的应用不受这个改动影响 —— [论坛](https://forum.vvvv.org/t/total-frame-drop-out-including-audio-dropout-glitching/20701/11)
* 重大系统更新：不允许任何过期代码运行
* 重大系统更新：热替换现在更灵活，也承担了更多职责
* `EqualsCyclic` 现在有了 Epsilon 针脚
* 用 “Browsable packages” 设置取代了「中键点击导航到定义」，Open 命令和全局搜索都会应用它

### 变动

* 浮点数 IOBox：设定精度时现在也会把 StepSize 卡住，不让它比精度所允许的更细
* IPs 节点现在也返回 NetworkInterface 的类型
* Executor 节点现在允许用 SendString 节点给正在运行的进程发输入
* `Decons` 不再抛越界异常
* 微调了错误信息的冒泡。过去，一个大草图结构最深处的一个小错误，很容易把一切都变红，而要找出那个具体错误几乎不可能。我们现在换了一种策略：不再让错误流向系统的每个角落，而只让它在文档结构里向上流。这意味着切到文档的定义页就能轻松找到它们。在应用侧我们仍会生成一个错误，但那个后续错误现在会以一条简单警告继续冒泡，让用户知道更深处有问题。
* 编译命令（F4）现在也会触发当前画布里嵌套定义的重新编译
* API：HoveredElement 和 ActiveCanvasStream 现在用上了新引入的 Channel 类型
* 日志窗口里记录得更多了

### 修复

* 重大：运行时更健壮了 —— 用户运行时和编辑器运行时（也就是 IDE 及其扩展所在的那个）都是；优化了异常管理与启动
* CustomRegion API。若干修复，并确保各项语言特性能好好配合：从 `T` 到 `M<T>` 的自动转换现在在输入 BCP 上也管用了
* 修掉了臭名昭著的 “X is no X” 错误
* 编译器 bug 修复：极少数情况下编译器会试图把 T 转成 T 的 Monadic，而那并不赋值兼容；交叉连线的类型现在也正确了
* 若干与默认值相关的修复（深层泛化构造类型、递归泛化草图、通过反射 API 调用）
* 若干序列化 bug 修复（二进制的也在内）
* 给提示框一些关爱（修卡顿、崩溃、打嗝；对象查看器更好读了）
* 系统重负载时，提示框和基于查看器的 IOBox 更自信了：它们至少会努力做到每秒 5 帧；系统不重负载时则按 60 fps 更新
* 计时更新流畅、数字稳定
* 值查看：提示框里的时钟可视化反映主循环的帧率
* 修复了没有音频设备时 VL.Audio 里的空指针
* 修复了 `SingleInstance` 区块的 `ReleaseAndDispose` 模式在导出应用里不工作 —— [论坛](https://forum.vvvv.org/t/exported-application-hangs-on-exit-when-using-vl-io-mousekeyglobal/20840)
* 修复并补齐了 `StoreSequence` 节点的文档
* 修复了创建字典针脚组时的异常，以及一处内部相等检查导致无休止编译循环 —— [论坛](https://forum.vvvv.org/t/dynamic-inputs-cause-gamma-to-crash-in-a-very-strange-way/20748/3)
* 目标代码里的 SerializedDefaultValue 特性少了
* 修复了装了 Visual Studio 17.3 之后导出不再工作
* 修复了启用「出错时暂停」时的死锁
* 修复了不带时间同步运行时，seek 时间没有传给 ImagePlayer —— [论坛](https://forum.vvvv.org/t/imageplayer-stride-doesnt-preload-correctly/20956)
* 修复了用 `Surround` 命令创建的区块无法被替换 —— [论坛](https://forum.vvvv.org/t/its-not-possible-to-replace-regions-that-have-been-created-with-surround/20930/2)
* 修复了静态运算器内部不显示错误和警告
* 响应式区块 ForEach、ForEachKeep 现在会按常规方式捕获状态销毁时的异常：把节点染粉（而不是弹对话框）
* 帮助面板更快了，因为它不再每帧检查 NeedsLayout
* `Try` 区块现在也会捕获 Create 和 Dispose 上的异常；加了帮助文档 “HowTo Catch Exceptions With Try Region”
* 重启应用之后，提示框和 IOBox 更可靠地重新挂到新实例上
* 提示框和节点浏览器弹出时的干扰少了
* 去掉了粉色节点和提示框的闪烁
* 更好的自适应节点错误信息
* 修掉了「中键点击做的事和 Open 不一样」
* 编译器细节：类型参数不再有「必须不可变」这个念头
* 对齐节点、数据板和边界控制点，现在确实是在对齐节点、数据板和边界控制点
* 修复了后端不重新编译已改动的文档，进而导致注册了过期的服务

### Stride

* 3D 和 2D 图元的改进，见 [PR1](https://github.com/vvvv/VL.Stride/pull/561)、[PR2](https://github.com/vvvv/VL.Stride/pull/573) 和 [PR3](https://github.com/vvvv/VL.Stride/pull/574)
* `InstancingSpreadComponent` 接受更广的集合类型（而不牺牲性能）

## vvvv gamma 2021.4.10

2022 年 7 月 20 日发布

### 修复

* 反序列化 vl 文档：修复了 `Path` 类型的 IOBox
* Path IOBox 导出：若路径原先末尾没有 `\` 就不加上
* 修复了一处崩溃（爬取程序集时）
* 修复了当无效类型落进自定义区块（比如 `Do`）的输出控制点时的后端崩溃
* 修复了在较大文档里打草图时的卡顿
* 泛化字段值查看的热修复
* 修复了用 `Try`、`Comment`（……）做 surround 时，有些连线偶尔会变红
* 在 `ImagePlayer` 节点里强制对 SKImage 解码 —— 修复了配合 JPEG 时的白闪
* 修复了 vvvv.exe 没能正确关闭 —— [论坛](https://forum.vvvv.org/t/iresourceprovider-seems-not-to-dispose-resource/20676/3)

### 变动

* `Wanderer (2d)` 的起始位置现在在 Create 上初始化
* `Wanderer (3d)` 有了更好的默认值
* `ImagePlayer` 的 OnScanningComplete 现在只在第一个文件加载完之后才触发
* 编辑名字／标识符时不再能输入非法字符
* `Damper`、`Oscillator` 现在会就地改动它们内部的函数，以减轻垃圾回收器的压力。加了一个 `Clone` 运算器，`Example Oscillator cyclic` 里用它来可视化内部函数的不同快照。
* `Executor` 节点的输出现在一致了

### 新增

* 编译本地草图：按 `F4`。理想世界里这没必要 —— 编译器会重新编译一切被你的改动间接影响到的草图。但在现实世界里，若这没发生（比如某个不该红的节点或针脚红了），你可以按 F4。
* 给进阶集合类型加了 `MutableArraySegment`

### Stride

* `MeshModel` 和 `MeshesModel` 节点现在能正确处理 `BoundingBox` 和 `BoundingSphere`
* 加了实验性的 `Text [Stride.Models]` 节点，用来在 3D 空间里简单地摆放文字
* 加了 `ViewportGrid` 节点
* `MeshSplit` 节点现在能处理没有 IndexBuffer 的网格
* 加了对预编译着色器的支持

### 节点浏览器

* 节点浏览器现在提供重载，而不是单个针脚的候选。每一条都代表一个节点
* 去掉了 OK 和 Cancel 按钮
* 修复了智能节点过滤：`Spread<string>` 现在能连到 `BinarySearch (KeySelector)`
* 即使没按 `External` 按钮，来自外部节点的针脚候选也会显示（因为用户已经认下了那个外部类型）
* 修掉了一个「意外自动选中区块」的 bug（选 `GroupBy` 时会引用 System.Linq）
* 修掉了一个「针脚候选太多」的 bug（列 BinarySearch 重载时出现一堆 `T` 类型的候选）
* 弹出的针脚候选少了（`A<T> == A<T>` 的相等检查现在管用了）
* 单针脚候选模式（它已不再是默认）现在会尽可能挑最短的那个节点。若你想要别的针脚，再打开一次节点浏览器即可。
* 若只剩进阶重载就不再问针脚候选：我们只有一个非进阶的 `Deserialize` 节点，直接自动选它
* 修掉了某些节点创建不出来的 bug：`System.Text.Json.JsonsSerializer` 的 `Serialize` 和 `Deserialize` 重载

* 许多新的着色器工具和函数
* ImagePlayer，用来播放图像序列

* 许多小改进与修复

### API 相关改动

* 注册服务的方法只在启动草图时被调用，打草图过程中不再调用。这应该能省资源，也让行为可预测得多。
* 节点路径现在由唯一（且持久）的 id 构成，元素可以跨会话被识别。老的 API 出于兼容仍在。想用新的就得相应调整用到它的草图。
* 加了新节点 `Using (RefCount)` 和 `Producing (RefCount)`，用来对特定资源做引用计数。`FrameDelay`、`S+H` 和 `HoldLatest` 用上了 `Using (RefCount)`。这样比如就能对 Skia 图像做帧延迟而不必克隆它们。
* 更宽松的值反序列化 —— 允许在单值和向量之间无缝切换。比如把 `float (+) (1f)` 变成 `Vector2 (+)` 时，那个 `(1f)` 会被扩展成 `(1f, 1f)`，而不是归零。
* 加了扩展方法 `IVLObject.TryGetPath` 和 `IVLObject.IsSupportedCollectionType`（从 VL.Elementa 移植过来）。所用的遍历方法现在也支持字典。

### 修复

* 修复了对空 path 对象调用 GetFiles/GetDirectories/GetDescendants 时的空引用异常（可以回移）
* 修复了使用特殊字符或保留关键字时的一些 emit 崩溃
* 修复了各类元素的重命名。重命名现在只在用户确认之后才应用，而不是每敲一个键就应用。
* 运行时停止时导出也能工作
* 减少了生成的临时项目数量 —— 修复了导出时着色器会互相重叠的情形
* 修复了同一个 shaders 子文件夹被复制到多个导出项目里
* 导出器现在会在「所生成项目属于某个包」时，为那个原始 NuGet 添加一条包引用 —— 确保这个包的所有构建目标都被拾取、文件都被复制到输出文件夹
* 修复了序列化器没有保住根元素的运行时类型
* 修复了在嵌套循环里使用、且第一帧 `Keep` 为 false 时 slice 状态没被销毁
* 修复了自适应实现的内容被内联时的 emit 异常
* 文档现在可以完全重新加载而不让编译器崩溃
* 「绑定到文档」的渲染窗口现在总会关掉正确的文档，哪怕这些窗口被包在某个辅助节点里
* 应用草图里的定义与定义草图里的定义得到相同的归类
* 连线提示框会按设置里指定的延迟出现（在有警告或错误、或按住 `Ctrl` 或空格时）
* 修复了 SKImageFilter 和 SKColorFilter 的提示框
* 优化了 TextureViewer 可能在内容就绪前就显示纹理信息的问题
* 被钉住的提示框不再那么啰嗦
* 修复了 PerspectiveLookAtRect。缩放部分挪进了 ProjectionMatrix，让 LookAtRectCam 能配合更多着色器工作。
* 修复了在没装 VL.Elementa 的情况下打开 VL.Devices.uEye 时的崩溃

* 修复了反序列化「使用打出来的泛化类型的对象图」时的崩溃（由 VL.Fuse.Control 暴露）

* 修复了打开某个草图时的界面崩溃 —— 当其中某个 IOBox 存了最小最大值而其类型变了时
* 修复了帮助面板对第一次点击没反应
* 修复了较大草图改动之后重新编译时的后端崩溃
